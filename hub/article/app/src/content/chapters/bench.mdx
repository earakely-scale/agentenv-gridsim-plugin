## The v4 benchmark

The benchmark plays the desk's v4, Weather Front: three operating days in a row across a real Texas weather front,
from 06:00 the day before the first, with three day-ahead markets to bid as ERCOT's forecasts move. Its {F.bench.n}
windows cover {F.bench.fronts} fronts at {F.bench.sites} real batteries, half from {F.bench.side.pre.name}, which may
be in the models' training data, and half from {F.bench.side.post.name}, after every model's reported training cutoff.
Each model runs in a native agent harness, once per window, on the same desk, tools and grading as the development
runs further down. The headline is C, hindsight capture: the share of the hindsight optimum's profit over idle that a
desk captures.

### How it was run

Each episode is a plain `agent-env run` of the published bundle `bench/desk-v4-bench`, at the tag
[`desk-v4-bench-run1`](https://github.com/earakely-scale/agentenv-gridsim-plugin/tree/desk-v4-bench-run1/bench), with a
config.toml that names the model endpoint, on agentenv-framework {F.bench.framework}. The desk inside the bundle is
v4's, frozen at `desk-v4-freeze`, with its own hook and verifier. Each harness keeps its local workspace, has its web
tools off and has its internet egress blocked.

  {F.bench.text.reliability}

**Reproduce it.** From a checkout of the plugin, `scripts/desk_bench.py` writes a bundle for one harness
(`claude-code`, `codex-sol`, `codex-luna`, `gemini` or `opencode-qwen`), and `agent-env run` plays one window of it,
with a `.agentenv/config.toml` that names the model endpoint and its key and a sandbox provider that enforces the
bundle's network allowlist:

```bash
uv run python scripts/desk_bench.py tasks --harness codex-luna \
  --pack desk-v4-bench --out bundles/bench-codex-luna
uv run agent-env run bundles/bench-codex-luna \
  --task desk-v4-2026-07-04-S01
```

Every grade, its references and every scored Episode JSON are in
[`results/desk-v4-bench`](https://huggingface.co/datasets/earakely-scale/GridSimEnv-AgentEnv/tree/main/results/desk-v4-bench)
and the dataset's `desk_v4_bench` config, one row per model and window, and the viewer's
[benchmark page](https://earakely-scale-gridsimenv-agentenv.static.hf.space/results.html?v=bench#replays) replays every model's run of every window.
