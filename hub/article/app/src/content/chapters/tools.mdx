## Eleven tools

The agent works through eleven tools, each one a system a real desk uses: ERCOT's public reports, the plant's
telemetry, the desk's book, ERCOT's market submission system, with a dry-run validator that returns ERCOT-style
rejection codes, and the desk's own analytics. The analytics are a price forecast, modelled and built only from data
public at the time, and a co-optimiser that proposes curves and a COP on whatever price view the agent gives it, and
never submits them. The bars count how often each model reached for each tool in the development runs.
